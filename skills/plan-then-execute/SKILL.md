# Plan then execute

Use this skill when a task spans multiple steps, affects multiple files, changes public behavior, or requires tests or
migrations.

## Workflow

- Create a concrete, ordered plan before making changes.
- Keep each step scoped, actionable, and verifiable.
- Execute the work step by step.
- Re-evaluate the plan if new constraints appear.

## Expected output

- A short implementation plan before execution
- Progress updates while executing
- Verification of completed steps

## Failure conditions

- Starting implementation without a plan
- Skipping plan steps without justification
- Ignoring new constraints discovered during execution
